# MultiBot Web

SPA/PWA estática inspirada visualmente en el panel TomiOka y adaptada al catálogo de este repositorio. La API Node y el Blueprint de Render se configuran desde la raíz del proyecto. Consulta [`../docs/WEB.md`](../docs/WEB.md).

El portal muestra bots, plugins y perfiles de configuración; además incluye guía Termux, métricas y referencia de API. **No ejecuta bots de WhatsApp ni almacena credenciales de Baileys.** Universal Bot sigue siendo Termux-only.
